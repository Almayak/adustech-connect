# ADUSTECH Connect

ADUSTECH Connect is an independent student-focused social, academic, and connection platform for students of Aliko Dangote University of Science and Technology (ADUSTECH), Wudil.

> Meet. Connect. Match. Belong.

This repository is being initialized as a React/Vite/TypeScript frontend with Supabase integration. It must not imply official university ownership, sponsorship, endorsement, or management.

## Status

Foundation implementation is being added incrementally. Supabase configuration is required before authentication and database-backed features can run.

## Environment

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-key
```

Never expose a Supabase service-role key or an AI provider secret in frontend code.
